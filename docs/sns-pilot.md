# SNS 게시 실사이트 파일럿 절차 (인스타그램 · 유튜브 · 틱톡)

레시피(`app/main/features/ai/sns-publish.ts`)는 모의 페이지로 흐름·완료 신호·발행 금지를 검증했다(`build/verify-sns-publish-cdp.mjs`, 게이트 `verify:full`).
**실제 사이트 게시는 되돌릴 수 없고 계정이 필요하므로 자동화하지 않는다.** 아래 절차로 사람이 돌리고, 결과(스텝 수·호출 수·막힌 지점)를 이 문서 끝에 기록한다.

## 0. 준비 (1회)
1. 설정 > ✨ AI > 제공자 = **Claude Code(구독)** (또는 Codex). "CLI 세션 유지" 켜짐 확인.
2. 설정 > ✨ AI > 에이전트 자동화 > **자료 폴더** 지정. 그 안에 시험용 파일을 둔다: `photos/test.jpg`(1080×1080 권장), `videos/test.mp4`(짧은 세로 영상, 10초 내).
3. 브라우저에서 각 플랫폼에 **직접 로그인**해 둔다(에이전트는 비밀번호를 묻지 않는다). 2단계 인증도 미리.
4. 화면 인식(비전)은 `auto`(기본) 유지 — 인스타·틱톡은 아이콘 버튼이 많아 비전이 도움이 된다. 조작 속도는 `auto`(봇 탐지 사이트는 자동으로 사람 속도).

## 1. 게시 직전까지 (draft) — 먼저 이걸로 흐름 확인
1. 사이드바 ✨ AI → 글쓰기 스튜디오 → 발행처 **인스타그램 (게시물)** 선택.
2. 본문 칸 = 캡션, 태그 칸 = 해시태그(쉼표), 첨부 파일 = `photos/test.jpg`. "게시 페이지 자동 열기" 켬.
3. **📝 게시 직전까지** 클릭 → 에이전트가 인스타를 열고 파일 첨부·다음·캡션까지 한다. **공유하기는 코드로 차단**된다(`[모드: 발행 금지]`).
4. 트레이스에서 확인할 것: 파일 첨부가 `upload_file` 한 번에 됐는가(파일 창이 뜨면 실패 — SEC-2 가로채기가 동작해야 함), 캡션이 실제로 들어갔는가, 스텝 수(목표 6 이하).
5. 유튜브(발행처 **유튜브 (동영상)**, 제목 칸 사용, 파일 `videos/test.mp4`)와 틱톡(**틱톡 (동영상)**)도 같은 방식으로 draft 1회씩. 유튜브 draft 는 "비공개 저장" 까지 간다.

## 2. 실제 게시 (publish) — 계정에 실제로 올라간다
1. 시험 계정 또는 나중에 지울 게시물임을 확인한 뒤, 같은 입력으로 **📤 게시** 클릭.
2. 게시 버튼 클릭에 확인 창은 뜨지 않는다(정책: 게시/발행은 무확인). 돈·삭제 동작만 묻는다.
3. 완료 판정: 트레이스에 **"완료 신호 확인"** 이 뜨고 done 메시지가 "인스타그램 게시 완료 (근거: 문구 "게시물이 공유되었습니다" 확인)" 형태면 **모델 호출 없이** 끝난 것이다. 대신 done 에 "⚠ 게시 완료 신호를 확인하지 못했습니다" 가 붙으면 실제 게시 여부를 눈으로 확인하고 아래에 기록한다(완료 문구가 바뀐 것일 수 있다 → `COMPLETION_TEXTS` 갱신).
4. 실행 이력(🕘 이력)에서 스텝 수·토큰(usage) 을 읽어 기록.

## 3. 막혔을 때
- **파일 창이 떠서 멈춤**: 에이전트가 `upload_file` 을 이름 없이 불렀거나 가로채기 실패. 트레이스의 파일 업로드 결과를 보고 `verify-agent-safety` A9~A11 로 재현.
- **캡션이 안 들어감**(React 에디터): 트레이스에 "입력 반영 확인 실패" — click_at 후 ref 없는 type 경로가 동작했는지 확인. 실패 시 스텝 원문을 보고서에 첨부.
- **완료 문구 불일치**: 실제 화면의 완료 문구를 적어 `sns-publish.ts` 의 `COMPLETION_TEXTS` 에 추가(한/영). 완료 신호는 "새로 나타난 문구" 기준이라 동작 전부터 있던 문구는 통과시키지 않는다.
- **완료 신호는 게시/공유 버튼 클릭 직후에만 판정**된다. 캡션에 "공유되었습니다" 같은 문구가 들어 있어도 게시 전에 완료로 보지 않는다(하네스 S7). 다만 완료 문구는 문장 단위 고유 문구만 쓰므로, 플랫폼이 문구를 바꾸면 "미확인 경고" 가 뜬다 → 위 절차로 갱신.
- **봇 차단·비정상 활동 경고**: 즉시 중단하고 `probe-fingerprint-cdp` 로 지문 재점검. 조작 속도를 `항상 사람 속도` 로.
